# Charles · Egg Catcher

A pixel-art egg-catching game made from a kid’s drawings.

Play: https://tomislavrupic.github.io/charles-egg-catcher/

Use the arrow keys, on-screen arrows, or drag Charles. Catch 10 fresh eggs, then 20 cracked eggs, then 30 eggs of all types before endless play. Dodge rocks and enemies. Glowing blue eggs restore a life.
